# local-model-bench benchmark-v9.8.1

Publishes the completed candidate campaign, all four predeclared finalist
trajectories and the retained roster. **The scoring method remains v9.8**:
no runner/helper, task, grader, budget or permission changes. Original source
identities and all failed/partial results remain intact.

| Primary serving profile | Household, seeds 17 / 29 | Python, each seed | Full times |
|---|---|---|---|
| Logics-SWE IQ4_XS / llama.cpp | 11/12 / 11/12 | 3/3 / 3/3 | 11m34s / 8m27s |
| Groot text RCO / distributed Mei rc.2 | 11/12 / 10/12 | 3/3 / 3/3 | 10m19s / 10m14s |

Retain both useful tradeoffs. All 480 finalist resource observations were normal,
with no swap growth in any run. All scripts reproduce on four isolated variants.
Logics failed an unfinished retry and a denied private read; Groot repeated a
deleted value on both seeds and attempted one unassigned route call before
recovering on seed 29. Neither is universally reliable, and two trials do not
establish statistical superiority or actual Peixinho app acceptance.

ThinkingCap and MiniCPM remain alternatives on explicitly historical evidence;
Clover stays experimental at 8/12 household+2/3 Python on v9.7. Its real native
32-row diffusion, tools and cold/cache controls are preserved; a Mei port is
deferred because current quality does not justify it. Qwen/Ornith remain
reference-only, and Flint/JANGH2 stays user-retired. No staged weights are removed.

The review also corrects stale roster text, broken inline command paths and a
misleading interpretation of the composite retry-receipt check. Groot's public
model card now records released Mei support and both repeats; anonymous readback
confirms only README changed, leaving every weight/config/tokenizer blob and
the original tested snapshot intact. Diagnostic replay of 72 historical household
trajectories finds no changed reference grade; it creates no new benchmark score.

Mei rc.2 is released and installed, with full native acceptance and real scored
runs on the exact distributed assets. Stable promotion/status responsiveness,
real Peixinho integration and universal numerical/long-context parity remain
separate open work. The source patch for Clover's loader is publicly reproduced
from a licensed base/patch/tree, not presented as an upstream release.
